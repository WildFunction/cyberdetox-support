# CyberDetox Support

CyberDetox helps you set daily limits for distracting apps on iPhone.

## Get help or send feedback

- Email: [jiehaozhang17@gmail.com](mailto:jiehaozhang17@gmail.com)
- Public bug reports and feature requests: [GitHub Issues](https://github.com/WildFunction/cyberdetox-support/issues)

When reporting a problem, please include your iOS version, what you expected to happen, what happened instead, and the steps to reproduce it. You can find the diagnostic log in CyberDetox Settings. Review it before sharing it by email; the app does not send it automatically.

**Do not post diagnostic logs, screenshots containing personal information, or other private details in a public GitHub issue.** Send those by email if needed.
